# Stalingrad ’42 추축군 오토마 근거표

## 0.2 재설계 규칙 감사

0.2는 점수식 후보 평가를 작전 목표와 행동별 순서도로 교체한다. 다음은 영문 규칙 v2.1에서 직접 확인한 원 게임 절차다. 오토마의 선택 우선순위는 이 절차를 변경하지 않는다.

| 실제 단계·결정 | 영문 규칙 | 0.2 처리 |
| --- | --- | --- |
| 추축 초기 단계의 자원·증원·대체 등 | 3.0, 18.1, 18.6.4, 21.0, 22.1 | 규칙 체크리스트와 목표별 자원 우선순위 |
| 이동 및 첫 턴 전술 이동 제한 | 3.0, 5.0, S1.2 | 편제·유닛·헥스 우선순위, 1턴 제한 확인 |
| 공격과 실제 CRT 해결 | 8–10 | 공격 기회와 지원 선택; 1–6 CRT 면수 정책은 오토마 실험값 |
| 추축군 방어·손실·퇴각 | 10.2, 11, 12 | 소련군 차례에도 오토마 방어 순서도 사용 |
| 회복 | 13.4–13.5, 21.4 | 자동 회복·집결·표식 제거 체크리스트; 임의 `재편 행동` 없음 |
| 보급 | 16.1, 16.5, 17.2.1, 18.6.4 | 철도두 → 보급 → 고립 손실 → ASU 순서표; 임의 `보급 회복 행동` 없음 |
| S1 승리 | S1.3, 24.1.1, 24.1.4 | 순 VP·감점·출구 전체 조건을 작전 목표 판단에 반영 |

0.1의 `SAFE-SUPPLY` 등에 적힌 `21–23`은 보급 규칙의 주된 참조가 아니다. 올바른 보급 판정은 16장이다. 0.1의 인쇄물과 웹은 후보 평가에는 일치했지만, 소련군 전투 중 추축 방어를 선택하지 않았으며 회복·보급을 임의 행동처럼 표현했다. 0.2의 정책과 화면에서는 이 경계를 바로잡는다.

## 참조 오토마에서 가져온 구조

Erasmus의 전황→목표→병력 순서, Enemy Action: Kharkov의 위험 우선 검사, Enemy Action: Ardennes Allied/German Solo의 편제별 목표와 실패 대체 경로, Europa Universalis 봇의 공통 선택 규칙과 난이도 매개변수를 참고했다. 다른 게임의 전투 수치나 승리 규칙은 사용하지 않는다.

## 종이판 추적 사례

1. 2턴, 0VP, Voronezh 접근 후보가 합법·보급·포위 안전·예비 병력 충족이라면 `START → GOAL-VP → SAFE-INPUT → PHASE-ACTION → SAFE-USED → S1-FIRST-TURN → SAFE-LEGAL → SAFE-SUPPLY → SAFE-ENCIRCLE → GOAL-REACH → SAFE-RESERVE → ACT-ATTACK → CHOOSE → CONFIRM`이다. 실제 헥스 이동은 영문 5–8에 따라 확인한다.
2. 7턴, 3VP, Rostov 접근 후보가 보급 단절이라면 `SAFE-SUPPLY → NEXT`. 다른 후보가 없으면 `FALLBACK`의 보급 회복을 검토한다. 높은 VP 가치도 안전 탈락을 뒤집지 않는다.
3. 공격 후보의 예상 비율이 선택한 난이도 기준보다 낮으면 `ACT-ATTACK → NEXT`. 다른 후보가 없다면 보급 회복→재편→방어 준비 순으로 실제 가능한 행동을 찾는다. 전투 적격성 확인과 영문 9–16의 실제 CRT 해결은 별도다.
