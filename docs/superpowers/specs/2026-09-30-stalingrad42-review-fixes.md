# 추축군 오토마 0.2.1 검토 반영 설계

사용자는 0.2 검토의 7개 항목 반영을 승인했다. 직접 구현하고 기존 offwork 경로에 배포한다. 실제 헥스 합법성과 CRT 해결은 영문 규칙으로 사람이 확인한다.

## 작전과 병력

전투단은 실물 카운터의 군 또는 사용자가 식별한 묶음이다. 사용자는 ID, 유닛 ID 목록, 기동/보병 유형, 가용·보급·핵심 거점 경계 상태와 목표까지 최소 헥스 거리를 관측한다. 임무는 사용자가 고르지 않는다. 오토마가 긴급 보급 구제, 주공, 제한 위협 대응, 예비, 측면 방어 순으로 중복 없이 배정한다. 이동 유닛은 배정된 전투단에서 보호 유닛을 제외하고 미이동 ID 순서로 제시하며 사람이 첫 합법 유닛·헥스를 확인한다. 명백히 보급이 없는 전투단은 주공에서 제외한다.

위협은 발생 예상, 피해 규모(핵심 병력·보급 붕괴 / VP·거점 상실 / 경미한 압박), 관련 목표 또는 영향받는 전투단으로 관측한다. 종료 이후 위협을 제외한다. 즉시 핵심 붕괴는 승리 목표보다 우선하되, 미래 위협과 경미한 위협은 즉시 승리를 밀어내지 않는다. 제한 대응은 매개변수의 병력 상한 안에서 배정하고 주공을 유지한다.

## 전투

안전한 진격은 목표 점령뿐 아니라 목표 접근·포위·돌파 기회도 평가한다. 돌파집단과 남은 진격 허용량을 사람이 확인하고, 합법·보급·반격 안전·목적을 검사하여 돌파전투를 선택한다. 자군 손실과 적군 손실의 선택 기준은 별개다. 지역 후보를 추가하면 오토마가 공통 정렬표로 선택한다.

CRT 면수는 점령 성공 확률이 아닌 공격 유효성 지표다. DR 등 수비측 퇴각/제거/돌파를 제공하는 면을 세되 실제 DD 성공과 후속 점령을 보장하지 않는다. DD 가능 여부와 강한 방어(도시·요새·유리한 선도 DRM)에 따라 필요한 면수를 추가한다. 가용 지원 수와 난이도별 준비 정책은 같은 평가에 반영한다. 공격의 즉시 승리 기준은 현재 작전 계획에서 도출한다.

## 기록과 표시

전황 수정은 계획·진행 중 판단을 함께 무효화한다. VP 관측 후 행동을 처리하면 VP 재확인이 필요하다. 계획 기록에 전황 전체, 병력·위협, 이전 목표, 공개 d6와 실제 정책 매개변수를 저장해 재실행할 수 있다. 관측 ETA는 관측 턴을 저장해 턴 경과를 반영한다.

정책 0.2.1, 저장 스키마 2를 유지한다. 이전 0.2.0 기록을 열면 상태를 명시적으로 전환하고 기존 기록 이력을 유지하며 구형 계획·진행 중 판단을 취소한다. 병력 장부가 없으면 새 계획 전에 등록한다. 종이판과 웹판은 공통 정책·정렬표를 사용한다. 목표 승률은 계속 미측정으로 표시한다.
