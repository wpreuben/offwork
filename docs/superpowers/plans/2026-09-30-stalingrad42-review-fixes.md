# 추축군 오토마 0.2.1 구현 계획

> 실행: superpowers:executing-plans로 직접 구현한다. 검토 반영과 배포는 사용자 승인 범위다.

목표: 승인된 7개 검토 항목을 종이판과 웹판에 반영한다.

구조: 기존 목표 정책과 절차 그래프를 확장하고 `operations.js`에 전투단 임무 배정과 유닛 선택을 분리한다. 세션이 관측·정책 버전·재현 기록을 관리하고 화면은 이를 표시한다.

## 검토 초점

- 마지막 턴 미래 위협과 즉시 승리의 우선순위, 경미 위협의 병력 상한
- 전투단·유닛 중복 배정, 보호 병력과 예비 유지, 가용 병력 없는 목표
- DD 보정·자군/적군 손실·목표 접근 진격·돌파 잔여 허용량
- 전황 변경 중 판단 및 VP 관측 무효화, 턴별 ETA·구형 기록 전환
- 종이판 정책 일치, 실제 브라우저 계획부터 전투·JSON 재개 전체 흐름
