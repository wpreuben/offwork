# 규칙 근거와 구현 경계

## 자료와 우선순위

1. 사용자의 명시적 정정: 마타 하리의 번호는 **동맹군 #17** (2026-09-17).
2. `images/CDG솔로시스템-패스오브글로리_공식용어수정.pdf`, 1쪽.
3. `images/CDG솔로시스템-공통규칙_공식용어수정.pdf`, 1쪽.
4. 제공된 전략 카드 이미지: 카드 번호·작전값·CC·전쟁 투입 단계와 원문 이미지.

두 PDF의 텍스트를 `rules/common.txt`, `rules/paths-of-glory.txt`로 그대로 추출했다. 텍스트 파일 자체에서 #22를 #17로 바꾸지 않는다. 이미지의 다른 번역 용어는 이미지 자체에 보존하고 앱 안내는 PDF의 공식 용어를 사용한다.

## C 슬롯과 보충의 표현

C는 받기 더미 자체다. A/B/D/E 보충 시 현재 C의 맨 위 카드를 꺼내므로 새 맨 위 카드는 기본적으로 뒷면이다. 주사위 1에서 C를 사용한 경우에는 새 C를 앞면으로 놓는다. 2~6 결과에는 새 C를 공개하라는 지시가 없어 뒷면으로 둔다. 별도 주사위 공개나 전투 보충 지시는 이를 덮어쓴다.

`slots`가 비어도 `faces`에는 그 슬롯의 이전 면 상태를 남긴다. 주사위 2~6은 이 상태대로, 주사위 1은 앞면으로, 전략 카드 받기는 뒷면으로 채운다. 보충이 받기 더미의 마지막 카드를 소비하면 즉시 남은 카드 수를 최대 4로 제한한다.

## 원래 게임에서 확인해야 하는 사항

두 PDF에는 지도 상태, 유닛 이동·전투 판정, 전쟁 상황 값, 이벤트의 전체 선행 조건, 강화/충원 절차가 없다. 앱이 이 조건을 추정하지 않는다.

- 사용자는 카드 선택 시 `base_legal`로 원래 게임의 사용 조건을 확인한다. LLM도 같은 확인이 필요하다.
- 일반 카드의 이벤트 후 제거 여부는 카드 문구에 따라 직접 선택한다. ‘8월의 포성’ 이벤트는 제공된 이미지의 제거 지시를 검증한다.
- 주사위 2의 이벤트 후보는 앞면 비전투 카드다. 실제로 가능한 이벤트인지 최종 확인해야 한다. 최저 OPS의 작전 사용은 서버가 계산한다.
- 카드가 부여하는 추가 카드 효과의 구체적인 보드 처리는 사람이 한다. 공통 2.2의 Cards Remaining 미감소만 옵션으로 적용한다.
- 카드 문구 고유의 일반적인 덱 조작/임의 셔플은 자동화하지 않는다. 앱에 있는 셔플은 PDF가 설명한 고갈 및 전쟁 투입 단계 상승이다.
- 고갈 시 자동 작전은 카드 사용이 아니므로 remaining을 줄이지 않으며 행동 라운드만 소비한다.
- 공통 4.3에 별도 예외가 없는 전투 카드 최초 사용은 remaining을 1 줄인다.

## PDF에 상세 절차가 없는 유지 전투 이벤트

PoG 시트는 전투 카드가 **버려졌을 때**의 보충을 명시한다. 앱에서는 전투 중 버림·제거할 앞면 CC를 처리한다. 전투 이벤트를 여러 전투에 걸쳐 유지하거나 재사용하는 상태 전이는 제공된 PDF만으로 확정할 수 없어 자동화하지 않았다. 지속 효과의 실제 적용은 기본 게임 규칙으로 관리하고 메모에 기록한다. 유지 전투 카드를 쓰는 완전한 기본 게임 엔진이 필요한 경우 해당 규칙을 추가 확보한 뒤 별도 영역과 수명주기를 구현해야 한다.

공통 4.1에 따라 양 진영의 남은 카드가 모두 0이면 나머지 빈 행동을 반복하지 않고 받기 준비 단계로 이동한다. 단일 진영만 0이면 그 진영의 차례를 넘긴다.

## 카드 메타데이터

`pog_cards.json`은 양 진영 각 55장이다. #1~14 동원전, #15~34 제한전, #35~55 총력전으로 원본 이미지의 단계를 따랐다. OPS와 CC는 이미지 상단/제목을 확인하여 전사했다. 숫자 외 이벤트 문구를 자동 해석하지 않는다.

마타 하리는 이미지의 #17/OPS 2와 공개 효과를 연결했다. PDF #22로 이름만 바꾼 카드나 서로 다른 번호의 중복 카드를 만들지 않는다. 수정 전 잠정 #22 처리는 배포되는 상태나 저장 파일에 남기지 않았다.

## 공식 구성품 반영 (2026-09-18)

사용자 제공 GMT Print & Play Kit: `Print_n_Play_Kit-Final_2.jpg` (파랑 디스플레이), `_4.jpg` (초록 디스플레이), `_6.jpg` (주사위·마커, © 2022 GMT Games, LLC). 원본 사본을 `web/assets/official/`에 보관하고 UI는 이미지와 CSS 표시 영역을 사용한다. 0~12 트랙 위에 현재 남은 카드/최대 핸드 마커를 표시한다. 파랑=동맹군, 초록=연합군은 UI 구분용이며 원문에서 진영을 지정한 것으로 해석하지 않는다.

주사위 도안 대응: 1=C·최저값·!!, 2=e·최저값, 3=ABC, 4=AB, 5=CDE, 6=DE. 숫자는 기존 JSON 프로토콜과 플레이시트의 행 번호이다. 실제 주사위 입력은 공식 기호로 고른다. !!는 여전히 PoG에서 무효다.

정적 배포용 `web/games/paths-of-glory.js`는 동일 규칙 어댑터이다. Python 테스트가 발생시키는 정상/거부 전이를 그대로 재생해 상태, 메시지, 후보, 공개 상태를 대조한다. UI/저장 계층에 규칙 판정을 중복하지 않는다.
